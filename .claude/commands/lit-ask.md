蓄積文献に基づいて質問に回答する。

引数 $ARGUMENTS を質問として使う。

手順:
1. `uv run litkit ask "$ARGUMENTS"` を実行して関連文献を検索する
2. 関連カードの内容を読み込む
3. 質問への回答を生成する

**絶対に守ること:**
- 回答の各文に必ず根拠カードIDを付す（例: [cinii-123456]）
- カードに根拠がない場合は「蓄積文献中に該当なし」と答える
- 推測で補完しない
- abstract_only のカードを根拠にする場合は「アブストのみに基づく」と但し書きを付す
- 該当が薄い場合は「この観点の文献が不足している」と指摘し、検索クエリ案を提示する
